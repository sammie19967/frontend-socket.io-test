This the <<jumanj live app frontend


This project aims to create a web application for ecommerce using websockets for real time updates

it entails chat features and live streaming 

This is to make the ecommerce activities between sellers and buyers to be more lively and bring a new dimansion towards ecommerce apps

Standout features

1. Tiktok like UI - i believe most people like tiktok because if its UI and UX so i decided to use a similar approach so that those transitioning from tiktok will have an easier time and a less steeper learning curve

2. Live Streaming - Large groups of youths and people go online especially on tiktok on daily basis to advertise goods and services. So this platform aims to give space for proper ecommerce activities like bargaining, live angagement for clients and sellers
Unlike ecommerce platforms like <Jumia where you cant bargaain or even see the one selling the product. You can do enquiries or complaints and get instant feedback

3. Chat features - If you likes a product or service you can dm the seller right away and negotiate, agree on payment methods, delivery etc in private 

4. Comment section - Complaints, suggestions, compliments can be put here for others to see, sellers cant delete them or turn them off without admins intervention, this will help curb the scamming problems

5. Verification badges- Verified sellers can be trusted by clients. 

6. Interactivity - Customers can engage the sellers live, by sending emojis, live comments, gifts etc. 

7. Product Listings - Sellers can also post an item into the feeds section, but in this case not like the traditional ecommerce layouts, this time it has options for likes, comments, reviews , views , ratings and finally an option to dm the seller for 
real time bargaing or negotiation

8. Good UI and UX and HCI principles used for seamless system usage 


Tech Stack

Websocket.io - real time chat and coments and likes
WebRTC - realtime video and audio conference
Vite - Frontend UI state management etc
Express.js - Backend authentication, RBAC
Mysql DB - Database

HOW TO RUN
1. CLONE THE FRONTEND https://github.com/sammie19967/frontend-socket.io-test.git
2. CLONE THE BACKEND  https://github.com/sammie19967/live-ecommerce-backend.git
3. EXTRACT THEM 
4. OPEN THE FRONTEND IN THE TERMINAL
5. RUN NPM INSTALL
6. CD INTO THE BACKEND
7. RUN NPM INSTALL
8. CREATE A .ENV FILE FOR PORT NUMBER AND SQL CONFIGS
9. RUM NPM RUN DEV TO START THE SERVER
10. START THE FRONTEND USING NPM RUN DEV
11. SIGN UP, LOGIN TO ACCESS FEATURES
